# Design Principles

## Direction

- Keywords: `organized`, `trustworthy`, `fast scanning`, `field-friendly`
- Visual tone: `Industrial Calm`
- Priority: visual polish is secondary to clarity, speed, and consistency

## Core Principles

1. Use one consistent visual language across login, dashboard, list, detail, and form pages.
2. Optimize for desktop workflows first, while keeping mobile layouts usable.
3. Emphasize structure with spacing, borders, and typography before using strong color.
4. Treat status colors as semantic signals, not decoration.
5. Prefer reusable patterns over page-specific styling.

## Reference Mood

- Calm industrial control panel
- Clean cards and restrained color usage
- Strong information hierarchy
- Reliable and operational rather than trendy

## Prohibited Patterns

- Different accent colors for each page
- Inconsistent radius per component group
- Repeated ad-hoc pixel values
- Heavy inline styles
- Overuse of gradients and decorative effects
- Dark mode before light mode is stable
