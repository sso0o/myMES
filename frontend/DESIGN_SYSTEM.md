# MES Frontend Design System

프론트엔드 디자인 시스템의 진입 문서입니다. 세부 규칙은 아래 문서로 분리했습니다.

## 문서 구조

- [01. Principles](./docs/design-system/01-principles.md)
- [02. Tokens](./docs/design-system/02-tokens.md)
- [03. Components](./docs/design-system/03-components.md)
- [04. Page Patterns](./docs/design-system/04-page-patterns.md)
- [05. Implementation](./docs/design-system/05-implementation.md)

## 사용 순서

1. 먼저 `Principles`에서 디자인 방향과 공통 원칙을 확인합니다.
2. 실제 스타일 구현 전에는 `Tokens`를 기준으로 색상, 간격, 타이포를 맞춥니다.
3. 공통 UI를 만들 때는 `Components`를 따릅니다.
4. 화면 단위 설계는 `Page Patterns`를 기준으로 맞춥니다.
5. 실제 반영 순서는 `Implementation` 체크리스트를 따릅니다.
