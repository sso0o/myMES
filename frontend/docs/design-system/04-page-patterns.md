# Page Patterns

## Global Layout Rules

- Use `background` as the full app backdrop.
- Place main content inside `surface` panels and cards.
- Standard page order:
  1. page title
  2. one-line description
  3. primary actions
  4. filters or search
  5. main content
- Avoid overly wide content areas.
- On mobile, stack panels vertically and reduce horizontal density.

## Login

- Single centered panel
- Minimal fields
- Clean hierarchy with strong trust signal

## Dashboard

- Top: KPI summary cards
- Middle: today's work / active orders
- Bottom: alerts, issues, and recent changes

## List Pages

- Top toolbar with filters, search, and main action
- Main area centered on table or structured list
- Fast scan and batch action readiness are priorities

## Detail Pages

- Top summary card
- Middle structured information groups
- Lower related history, logs, or linked entities

## Create / Edit Forms

- Single-column or grouped two-column layout
- Save action stays visually stable and easy to find
- Group fields by operational meaning, not by raw database structure
